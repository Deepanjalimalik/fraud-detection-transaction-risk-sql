# Fraud Detection & Transaction Risk Analysis

## Overview
This project analyses over 1.29 million credit card transactions using SQL in SQLite to identify fraud patterns, high-risk merchant categories, geographic fraud concentrations, and anomalous spending behaviour.

## Tools Used
- SQL
- SQLite
- DB Browser for SQLite

## Dataset
Credit Card Fraud Detection Dataset from Kaggle.

## Key Analyses
- Overall fraud rate calculation
- Fraud-prone merchant category analysis
- High-risk transaction classification
- Geographic fraud trend analysis
- Spending anomaly detection

## Key Findings
- Identified 7,506 fraudulent transactions from 1.29M+ records
- Calculated an overall fraud rate of 0.58%
- Online shopping categories showed the highest fraud exposure
- High-value travel transactions were frequently flagged for review
- Fraudulent transactions consistently showed higher spending behaviour than legitimate transactions

## SQL Concepts Applied
- Aggregation functions
- GROUP BY analysis
- CASE statements
- Fraud rate calculations
- Spending anomaly analysis
